Mode d’emploi

Sélection
Cochez les denrées à acheter. Ajoutez-en une avec le champ prévu, puis touchez Valider la sélection.

Courses
Dans « Chercher », cochez les articles trouvés. Ajoutez si besoin une précision dans le champ à droite ; ils apparaîtront ensuite dans « Trouvés ».

Nouvelle course
Revenez dans « Sélection » et touchez « Tout décocher ».

Dictée
Si le téléphone, le navigateur et les autorisations le permettent, touchez « Dictée », énoncez les denrées, puis touchez « Arrêter » et « Ajouter ». Sinon, utilisez le micro du clavier.
