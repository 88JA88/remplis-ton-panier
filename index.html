Mode d’emploi

Sélection :
Pour ajouter une denrée, écrivez ou dictez son nom puis touchez « Ajouter ».
Cochez les denrées que vous souhaitez acheter. Touchez « Valider la sélection » pour créer votre liste de courses.

Courses :
Dans « Chercher », cochez les articles trouvés dans le magasin. Les articles cochés apparaissent ensuite dans « Trouvés ».
Pour effectuer de nouvelles courses, revenez dans « Sélection » et touchez « Tout décocher ».

Dictée :
Si le téléphone, le navigateur et les autorisations le permettent, touchez « Dictée », puis énoncez les denrées en les annonçant avec une légère pause. Touchez ensuite « Arrêter », puis « Ajouter ».
Si la dictée n’est pas disponible, utilisez le micro intégré au clavier.
L’application peut être utilisée hors connexion après sa première ouverture.
